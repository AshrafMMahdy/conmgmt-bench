# Expectations — PRE-07

Outcome rules a good answer meets. Score each 0 / 0.5 / 1; see `scoring/HOW_TO_SCORE.md`.

1. Reads the subcontract AND the tender offer AND the main contract — the form-of-contract switch (tendered on YSE 1998, submitted on own conditions) is only visible by reading the offer.
2. Finds the planted back-to-back gaps in the key (the union of a careful read: liability cap, governing law, notice periods, payment terms, retention, security, delay damages, defects period, assignment, insurance, dispute forum, flow-down).
3. Each finding has a severity, the clause reference, and a prioritised change for the subcontractor.
4. No fabricated blockers: nothing is flagged as missing that is in the document.
5. Verdict: blocked / sign with changes / safe to sign, with the arithmetic of securities and retention correct.
