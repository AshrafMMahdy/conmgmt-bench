# Expectations — S6

Outcome rules a good answer meets. Score each 0 / 0.5 / 1; see `scoring/HOW_TO_SCORE.md`.

1. Ilmatek's quotation is checked line by line against the priced Bill and the records; each line is accepted, adjusted or rejected with the reason.
2. The valuation method follows the subcontract and the main contract (rates from the Bill where they apply; fair rates with basis where they do not).
3. The interim valuation to the Employer and the response to Ilmatek carry the same numbers.
4. When a figure is disputed it is resolved, not withdrawn: a deliverable that silently drops the numbers is a fail.
