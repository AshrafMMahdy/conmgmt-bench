# Expectations — PRE-04

Outcome rules a good answer meets. Score each 0 / 0.5 / 1; see `scoring/HOW_TO_SCORE.md`.

1. Finds Rev C without being told it exists (both revisions are in the folder; the user mentions only Rev B).
2. For each revision: what moved, what was left alone, what was added without being announced — against the prior analysis, not from scratch.
3. A clear verdict per revision: sign, or go back — and if back, the exact asks, clause by clause.
4. Revision diffs are readable by a non-lawyer (side-by-side or redline).
