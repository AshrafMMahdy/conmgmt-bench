# Expectations — PRE-10

Outcome rules a good answer meets. Score each 0 / 0.5 / 1; see `scoring/HOW_TO_SCORE.md`.

1. One marked-up plan per month for the whole construction period (Mar 2026 → Dec 2027, 22 months), external works included.
2. Sizing follows the company standard (PDC-LOG-001): parking, offices and welfare computed from headcount, not guessed.
3. Per-subcontractor compounds named and relocating with the fronts; cranes with radii; pedestrian and vehicle routes separated; the 110 kV constraint respected.
4. The three deliverables asked for (deck, spreadsheet, PM note) are delivered — and if one is not, the answer says so instead of substituting.
