# Expectations — PRE-09

Outcome rules a good answer meets. Score each 0 / 0.5 / 1; see `scoring/HOW_TO_SCORE.md`.

1. The drawing set is indexed (sheet, title, discipline, revision) from the files, including the scanned ones.
2. Scale is recovered from the drawing itself (title block or a dimensioned element) and stated with its basis.
3. Measured quantities (areas, the strip volume) are shown with the elements measured and the arithmetic; metric and imperial agree.
4. A deliverable is produced, not only an answer in chat.
