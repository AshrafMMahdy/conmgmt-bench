# Expectations — PRE-02

Outcome rules a good answer meets. Score each 0 / 0.5 / 1; see `scoring/HOW_TO_SCORE.md`.

1. Live formulas: the duration cell divides quantity by (crews × members × hours/day × rate); nothing typed as a result.
2. Every input in its own cell — quantity, crews, crew size, hours per day, rate, margin — so a reviewer can change one and watch the duration move.
3. Every rate traceable: the analog it came from (quantity, crew, duration → rate) or a stated assumption, never "typical".
4. The markdown write-up and the workbook agree with each other and with the programme's durations.
