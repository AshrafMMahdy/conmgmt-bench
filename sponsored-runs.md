# Sponsored runs

We will run the full ConMgmt-Bench set against a model or an agent you name, chained, and grade it on the published expectations and keys, with the outputs published next to the baseline.

- You cover the model cost (API usage at list price) and a flat grading fee; we publish the result whatever it says.
- You get the raw outputs, the scored sheet, and a short written read of where it was strong and where it broke.
- A run is one pass per scenario; a second pass with your preferred prompting is a second run.
- Grading is by the same people who graded baseline 1.0, against the same files; disagreements go in the sheet, not in the score.

Ask through the repository's issues or the contact in the profile.
