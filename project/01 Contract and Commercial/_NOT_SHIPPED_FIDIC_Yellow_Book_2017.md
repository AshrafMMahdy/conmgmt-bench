# FIDIC Yellow Book 2017 — General Conditions (not included)

The General Conditions are copyrighted by FIDIC and are not part of this repository. The Particular Conditions (Rev A, B, C) amend them by sub-clause number.

To run the contract scenarios as the baseline did, obtain a licensed copy and place it in this folder as `FIDIC_Yellow_Book_2017_General_Conditions.pdf`.

An agent given only the Particular Conditions should say it cannot resolve the amendments against the base text. That is a correct answer, not a failure.
